HackerRank Question — Python: Incorrect Regex

Problem:
You are given T strings. For each string, determine whether it is a valid regular expression.

Print:

True if the regex is valid
False if the regex is invalid
Input
2
.*\+
.*+
Output
True
False
CODE
import re

T = int(raw_input())

for _ in range(T):
    s = raw_input()
    
    try:
        re.compile(s)
        print "True"
    except re.error:
        print "False"
